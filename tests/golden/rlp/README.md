# RLP golden vectors

Contract for `src/nvnm_cite/chain/rlp.py` (encode-only).

Two independent sources:

1. **Published spec examples** hardcoded in `tests/test_rlp.py` ("dog",
   ["cat","dog"], the Lorem ipsum long string, the integer encodings 0/15/1024,
   and the set-theoretic nested list, all from the Ethereum RLP specification).
2. **`vectors.json`**, generated by `generate_vectors.cjs` with ethers
   `encodeRlp` as an oracle that shares no code with this repo. Cases straddle
   the 55-byte short/long boundary for strings and list payloads, the
   0x7f/0x80 single-byte edge, a 70 kB string (long-form length-of-length),
   and a legacy-transaction-shaped list.

Regenerate (only if adding cases; commit the diff):

    node generate_vectors.cjs <path to any node_modules/ethers>

Originally generated 2026-06-10 with ethers 6.16.0 from the sibling
nvnm-tutorial project's node_modules.
