# ABI / precompile golden vectors

Contract for `src/nvnm_cite/chain/abi.py` and `precompile.py`.

Two independent sources:

1. **Published selectors** hardcoded in `tests/test_abi_precompile.py`:
   the anchoring-module v1.2.0 doc (github.com/NVNM-Chain/nvnmchain
   v1.2.0, x/anchoring/readme.md) publishes all seven; records
   `0xc7be5e37`, registries `0x17bd3e65`, addRecord `0x64d25295` changed
   with the id-keyed interface, the other four are unchanged. All were
   confirmed by live dispatch on both networks 2026-07-31 (the old
   name-keyed selectors return "unknown method id").
2. **`vectors.json`**, generated by `generate_vectors.cjs` with ethers
   Interface as an oracle sharing no code with this repo, driven by the
   SAME vendored `anchoring.json`: all seven selectors, the five event
   topic hashes, calldata for every method (unicode strings, empty
   strings, non-empty pagination key), encodeFunctionResult blobs the
   Python decoder must read back exactly, and an AddRegistry log-data
   blob for the event decoder.

Regenerate (only if adding cases; commit the diff):

    node generate_vectors.cjs <path to any node_modules/ethers>
