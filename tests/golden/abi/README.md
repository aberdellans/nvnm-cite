# ABI / precompile golden vectors

Contract for `src/nvnm_cite/chain/abi.py` and `precompile.py`.

Two independent sources:

1. **Published selectors** hardcoded in `tests/test_abi_precompile.py`:
   addRecord `0x9b7b7869`, addRegistry `0x318b38b1`, records `0x02abafdf`
   came from the chain's own documentation via the original build plan and
   must match what we derive from the vendored ABI.
2. **`vectors.json`**, generated by `generate_vectors.cjs` with ethers
   Interface as an oracle sharing no code with this repo, driven by the
   SAME vendored `anchoring.json`: all five selectors, calldata for every
   method (unicode strings, empty strings, non-empty pagination key), and
   encodeFunctionResult blobs the Python decoder must read back exactly.

Regenerate (only if adding cases; commit the diff):

    node generate_vectors.cjs <path to any node_modules/ethers>

Originally generated 2026-06-10 with ethers 6.16.0 from the sibling
nvnm-tutorial project's node_modules.
