# Keccak-256 golden vectors

These vectors are the contract for `src/nvnm_cite/chain/keccak.py`.

Two independent sources pin the implementation:

1. **Published digests** hardcoded in `tests/test_keccak.py` (the empty string,
   `"abc"`, and the fox sentence are documented Keccak-256 values in the
   literature and across Ethereum tooling).
2. **`vectors.json`**, generated by `generate_vectors.cjs` using the ethers
   library as an oracle that shares no code with this repo. Lengths straddle
   the 136-byte sponge rate (135/136/137, 271/272/273) because padding bugs
   live at those boundaries; the 135-byte case forces the single-byte 0x81
   pad path.

Regenerate (only if adding lengths; commit the diff):

    node generate_vectors.cjs <path to any node_modules/ethers>

Originally generated 2026-06-10 with ethers 6.16.0 from the sibling
nvnm-tutorial project's node_modules.
