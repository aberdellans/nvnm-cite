# Signer golden vectors (EIP-155 legacy transactions)

Contract for `src/nvnm_cite/chain/signer.py`.

Two independent sources:

1. **The EIP-155 worked example**, hardcoded in `tests/test_signer.py`
   verbatim from eips.ethereum.org/EIPS/eip-155 (fetched 2026-06-10):
   signing data, signing hash, v/r/s, and the full signed raw transaction.
2. **`vectors.json`**, generated by `generate_vectors.cjs` with ethers
   Transaction as an oracle sharing no code with this repo. Includes the
   same EIP-155 example (the two sources must agree with each other) plus
   NVNM-testnet-shaped transactions: chain id 787111, the anchoring
   precompile as target, 40 gwei gas price, and a 600-byte calldata case.
   ethers signs RFC-6979 + low-s, so unsigned hash, raw bytes, and tx hash
   must match our output exactly.

Regenerate (only if adding cases; commit the diff):

    node generate_vectors.cjs <path to any node_modules/ethers>

Originally generated 2026-06-10 with ethers 6.16.0 from the sibling
nvnm-tutorial project's node_modules.
