# secp256k1 / ECDSA golden vectors

Contract for `src/nvnm_cite/chain/secp256k1.py`.

Three independent sources:

1. **RFC 6979 Appendix A.2.5** (curve P-256, SHA-256), hardcoded in
   `tests/test_secp256k1.py` from the RFC text at rfc-editor.org (fetched
   2026-06-10): the public-key pair validates the generic curve arithmetic,
   the `k` values validate the nonce derivation, and the (r, s) pairs
   validate the full signing equation on a second curve.
2. **`vectors.json`**, generated by `generate_vectors.cjs` with ethers as an
   oracle sharing no code with this repo: addresses, uncompressed public
   keys, and full signatures. ethers also signs RFC-6979 + low-s, so r/s
   must match our output exactly, not merely verify.
3. **Sign/verify round-trip and negative tests** in the test file itself.

Regenerate (only if adding cases; commit the diff):

    node generate_vectors.cjs <path to any node_modules/ethers>

Originally generated 2026-06-10 with ethers 6.16.0 from the sibling
nvnm-tutorial project's node_modules.
