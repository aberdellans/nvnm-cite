Check a document’s citations

Every case citation in your document is checked for existence against the NVNM registries of canonical US case citations. A green result means the citation string denotes a real published decision — never that the case supports your argument, and never that it is still good law.

Nothing leaves this machine. The document is processed in memory by the local verifier and discarded the moment your report is ready — no copy is kept, nothing is written to disk. Drafting-time checks run against a local index and make no chain or network requests, so not even an RPC operator can see what you are citing before you file.

Record the verification on NVNM Chain

This step anchors a filing receipt: an immutable, timestamped record that a citation check was performed on the document identified by its SHA-256 hash. The receipt proves the check happened, when, against which registry state, with what results, and who attested it. It does not — and cannot — assert anything about the document’s arguments.

What this system is — and is not

  

    

      
It proves provenance

      
That a citation string denotes a real published decision; that a check ran at a stated
      time against stated registry state; that a receipt is bound to one exact document by its
      SHA-256. Citations are stored and checked in plaintext — never hashed — so
      anyone can audit a registry record by reading it.

    

    

      
It never asserts truth

      
No holdings, no propositions, no good-law status, ever. A VERIFIED citation can still be
      overruled, distinguished, or cited for the wrong point. Shepardizing remains your job;
      NVNM Cite tells you the citation exists, and that you checked.

    

    

      
Drafting stays private

      
Checks run against a local index with no chain reads at all, because even read-only RPC
      traffic would reveal a brief’s citation set — your legal strategy — to the RPC operator
      before filing. The chain is touched exactly once, explicitly, at filing time.

    

    

      
Anyone can audit

      
Registries are public plaintext; the local index is rebuildable by anyone with an RPC URL
      (indexer rebuild-index), and every lookup this page performs can be replayed
      against any node — the verify tab hands you the exact call to reproduce.
