One-time setup: the receipts registry does not exist yet.

Receipts are anchored into a dedicated receipts-v1 registry. It has not been created on this chain. Any wallet may create it; creation is a single transaction:

addRegistry("receipts-v1", "nvnm-cite filing receipts", "sha256")
What the receipt asserts — and all it asserts
  1. A document with this exact SHA-256 fingerprint was citation-checked.
  2. The check ran against the named registries at the stated head block.
  3. It produced exactly these per-citation existence results.
  4. The record was signed by this address at this chain time.

It does not assert that any case supports any argument, nor that any citation is good law. Provenance, not truth.

About & status

NVNM Cite is a public registry of canonical US case citations and a receipt system for citation checks, running on NVNM Chain.

It proves provenance

A receipt proves a check happened: when, against which registries, over which exact document, attested by whom.

It never asserts truth

A verified citation exists in the registry. Whether it is good law, or supports an argument, remains the lawyer’s judgment.

Drafting stays private

Citation checks run locally and make zero network requests. Documents are never uploaded; only a fingerprint ever leaves the machine, and only if you record.

Anyone can audit

Registries and receipts are plaintext on a public chain. Verification is free and requires no wallet, no account, and no trust in this page.
